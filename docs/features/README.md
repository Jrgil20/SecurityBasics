# Features Documentation

This section provides detailed documentation for the main features of the Security Basics project.

## Overview

Security Basics includes several key features:

1. **Internationalization**: Support for multiple languages (English and Spanish)
2. **Theme System**: Light and dark theme support with system preference detection
3. **Blog System**: A comprehensive blog with articles on security topics
4. **Security Tools**: Interactive tools for security education

## Feature Details

Each feature is documented in detail in its own section:

- [Internationalization](./internationalization.md)
- [Theme System](./theme-system.md)
- [Blog System](./blog-system.md)
- [Security Tools](./security-tools.md)

## Feature Implementation

Features in Security Basics are implemented using a combination of:

1. **React Components**: UI components that implement the feature
2. **Context Providers**: Providers that manage feature-specific state
3. **Utility Functions**: Helper functions that support the feature
4. **API Routes**: Server-side API routes that provide data for the feature
