## Project Overview

Security Basics is an educational web application designed to help users learn about fundamental security concepts and best practices. The project aims to make security knowledge accessible to everyone through clear explanations, practical tips, and interactive tools.

### Key Features

- **Multilingual Support**: Full support for English and Spanish
- **Dark/Light Theme**: Customizable theme with automatic system preference detection
- **Security Knowledge Base**: Comprehensive blog articles on security topics
- **Interactive Tools**: Security checklist, password generator, and security quiz
- **Responsive Design**: Fully responsive layout that works on all devices

### Technology Stack

- **Framework**: Next.js 14 with App Router
- **Styling**: Tailwind CSS with shadcn/ui components
- **State Management**: React Context API
- **Internationalization**: Custom i18n implementation
- **Deployment**: Vercel
