# Development Guide

This section provides guidance for developers working on the Security Basics project.

## Overview

The development guide covers the following topics:

- [Setup](./setup.md): How to set up the development environment
- [Workflow](./workflow.md): Development workflow and best practices
- [Adding Features](./adding-features.md): How to add new features to the project
- [Best Practices](./best-practices.md): Best practices for development

## Development Environment

Security Basics is built using the following technologies:

- **Next.js**: React framework for building web applications
- **TypeScript**: Typed superset of JavaScript
- **Tailwind CSS**: Utility-first CSS framework
- **shadcn/ui**: Reusable UI components
- **ESLint**: JavaScript linter
- **Prettier**: Code formatter

## Development Process

The development process follows these steps:

1. **Setup**: Set up the development environment
2. **Feature Development**: Develop new features or fix bugs
3. **Testing**: Test the changes locally
4. **Code Review**: Submit a pull request for code review
5. **Deployment**: Deploy the changes to production
